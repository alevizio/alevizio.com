Privacy Policy

Last updated July 16, 2026

This policy explains how I, Alejandro Vizio, handle data across this website (alevizio.com) and the personal software tools I build and run for my own use — including the Alevizio MCP Connector for Pinterest. These are personal, single-user tools. They are not products offered to other people.

The Alevizio MCP Connector

The Alevizio MCP Connector is a personal Model Context Protocol (MCP) connector that runs locally on my own computer. It lets an AI assistant that I operate read and create pins and boards on my own Pinterest account, at my request, to help me organize my own design references.

  • Single user. It is used only by me, the account owner. It does not access, collect, or process any other Pinterest user’s data.
  • What it accesses. With my authorization through Pinterest’s OAuth flow, it can read my boards and pins (including private boards), read basic account information, and create boards and pins on my account. It only ever touches my own account.
  • Where the data goes. The connector runs locally. The OAuth token it receives is stored on my own machine and is never uploaded to, or held on, any external server. Pinterest data it reads is passed only to the assistant I run, at my request — it is not published, shared with third parties, sold, or used for advertising.
  • Retention and revoking access. The token stays on my machine until I delete it or revoke it. I can revoke the connector’s access at any time from my Pinterest account settings, which invalidates the stored token.

This website

alevizio.com is a personal portfolio. It does not require an account and does not ask visitors for personal information. It does not use advertising or cross-site tracking cookies. The hosting provider may keep standard server logs (such as IP address and request metadata) for security and reliability, as is typical for any website.

Third-party services

The connector interacts with Pinterest through its official API. Pinterest’s own handling of my account data is governed by the Pinterest Privacy Policy. This site and its tools do not sell data or share it with third parties beyond the services strictly needed to run them (Pinterest for the connector, and the website host).
