# Pausa — Case Study

The story of designing **Pausa**'s identity, the journal that pushes back:
the brief, the drawings, the system, and where it lives now.

**Live → [pausa.alevizio.com](https://pausa.alevizio.com)** (linked from alevizio.com at `/work/pausa`)

The page is built in Pausa's own visual language rather than a portfolio
template:
- pausa.co's paper texture and grain
- Source Serif 4, Caveat, Inter and IBM Plex Mono, each in its brand role
- the margin notes in the pen's blue
- the organic pen and highlighter marks, which draw themselves once as they
  scroll into view

## What's inside

- **I · The truth.** The brief, the positioning map, and the line everything
  was drawn from.
- **II · By hand.** The three directions, the drawn sheets and the cutting
  tool, the icon shoot-out, and all 47 drawings marked up the way Pausa marks a
  page.
- **III · The system.** Lockup construction, the three colour rules, four
  faces, the pen marks, and the voice.
- **IV · In the world.** The app, the App Store listing, the ads and pausa.co.
- **The handover.** The kit as it was delivered.

Images come from the brand book (Figma → PDF → WebP), the hand-drawn sheets in
the project repo, the final brand kit and the pausa.co design. None of them
shows a rating, a review, a price, another company's work or stock
photography.

## Stack

Next.js 16 (App Router) · React 19 · TypeScript (strict) · Tailwind CSS v4.
It deploys to its own subdomain on Vercel, like the Messa story.

## Run it locally

```bash
npm install
npm run dev
```
